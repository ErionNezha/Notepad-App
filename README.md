# 📝 Notepad App

Krijuar nga **Erion Nezha** — © 2026

Editor teksti në browser — port web i aplikacionit origjinal Python me tkinter.

## 🎬 Demo live

Hap `index.html` ose `demo/index.html` në browser. Funksionet:
- **New** — pastron editorin
- **Open…** — hap file nga kompjuteri (FileReader)
- **Save** — shkarkon me emrin aktual, ose hap Save As
- **Save As…** — shkarkon me emër të zgjedhur

## 🐍 Origjinali Python

`original/Notepad.py` — kopje e paprekur e burimit. Përdor `tkinter`:
- menuja File me New / Open / Save / Save As
- `filedialog` për hapje/ruajtje

```bash
python Notepad.py
```

## 📁 Struktura

- `demo/index.html` — versioni web funksional
- `original/Notepad.py` — burimi origjinal i paprekur
